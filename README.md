# Steep

*by Tea Powered Solutions*

**Steep shows Configuration Manager (MECM) teams what the MECM console doesn't: the devices, operating systems and applications that have quietly fallen through the cracks.**

MECM's software update compliance comes from WSUS scan results, and those are often wrong. Steep combines MECM data with Active Directory and Microsoft's own release and security data, and rates each device by its OS build revision, which shows its real patch level. It also finds broken MECM clients and repairs them, tracks vulnerable applications, and manages application versions, all from one web console that runs in your own network.
